You are required to design a comprehensive set of functional test cases for a basic four function calculator (addition, subtraction, multiplication, division). The calculator is assumed to be simple, meaning:
•	No scientific functions
•	No parentheses
•	No memory functions
•	Integer and decimal operations allowed
After designing the test cases, you will implement Python BDD (Behaviour Driven Development) automation to cover at least 2–3 of your test scenarios.
Your submission should demonstrate:
•	Clear, structured test design
•	Ability to think through edge cases
•	Clean, maintainable Python code
•	Understanding of BDD principles (Given / When / Then)
During the interview you will be asked to explain your work, how it is built and any considerations you have made in its creation.

Ви повинні розробити комплексний набір функціональних тестових випадків для базового калькулятора з чотирма функціями (додавання, віднімання, множення, ділення). Калькулятор повинен бути простим, тобто:
•    Без наукових функцій
•    Без дужок
•    Без функцій пам'яті
•    Дозволені операції з цілими та десятковими числами
Після розробки тестових випадків ви реалізуєте автоматизацію Python BDD (Behaviour Driven Development) для охоплення принаймні 2–3 ваших тестових сценаріїв.
Ваша робота повинна демонструвати:
•    Чіткий, структурований дизайн тестів
•    Здатність продумувати крайні випадки
•    Чистий, підтримуваний код Python
•    Розуміння принципів BDD (Given / When / Then)
Пояснити вашу роботу, як вона побудована та які міркування ви враховували під час її створення.
